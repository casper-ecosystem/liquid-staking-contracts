## CSPR.cloud requirements

1. As the LS platform backend, I should be able to use CSPR.cloud REST API to get CSPR/USD exchange rate.
1. As the LS platform backend, I should be able to use CSPR.cloud REST API to get any account CSPR balance.
1. As the LS platform backend, I should be able to use CSPR.cloud REST API to get any CEP-18 token balance for any account.
1. As the LS platform backend, I should be able to use CSPR.cloud REST API to get any CEP-18 token total supply. 
1. As the LS platform backend, I should be able to use CSPR.cloud Node Proxy to send a Deploy to the network.
1. As the LS platform backend, I should be able to use CSPR.cloud streaming API to listen to LS smart contract events.
1. As the LS platform backend, I should be able to use CSPR.cloud REST API to get LS contract purses staked amounts across all validators. 
1. As the LS platform backend, I should be able to use CSPR.cloud Node Proxy to get an unbonding balance
